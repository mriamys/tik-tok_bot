# TikTok Downloader Bot 📱

Telegram-бот для скачивания видеороликов из TikTok без водяных знаков в высоком качестве с обработкой медиа.

## Возможности

- **Скачивание без вотермарки**: извлечение оригинального видеопотока по ссылке.
- **Обработка через FFmpeg/FFprobe**: анализ метаданных, проверка ориентации и нормализация видео перед отправкой в Telegram.
- **База данных и кеш**: сохранение истории загрузок в SQLite (`videos.db`) для моментальной повторной выдачи.
- **Надёжная отправка**: поддержка отправки тяжелых видеофайлов и устойчивость к сетевым сбоям.

## Стек технологий

- Python 3.11+
- aiogram 3.x
- FFmpeg, FFprobe
- aiohttp, SQLite
- Docker Compose

## Установка и запуск

1. Настройте файл `.env`:
   ```env
   BOT_TOKEN=ваш_токен_бота
   ADMIN_ID=ваш_telegram_id
   ```

2. Запустите контейнер:
   ```bash
   docker compose up -d --build
   ```
